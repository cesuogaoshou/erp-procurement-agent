## Current Backend Acceptance Status

MySQL integration is now verified with the current `DATABASE_URL`, including migration head, deterministic seed counts, dual-session approval concurrency, duplicate approval idempotency, rollback, and Agent persistence after reconnect. SQLite tests still do not substitute for this check; rerun the opt-in MySQL tests when schema or transaction behavior changes. Real external DeepSeek/OpenAI-compatible Function Calling is accepted for the natural-language-to-draft path and controlled boundary states. Forecasting is frozen at service config `forecast_strategy_v1_20261011`: the actual service/tool strategy is hybrid dynamic-Prophet-or-moving-average, uses dynamic Prophet as the main model, and falls back to 30-day moving average for short history or Prophet failure. The hybrid strategy returns and persists model name, selected model, config version, training range, fallback reason, and forecast evidence through tool traces and purchase draft evidence payloads; it must not be described as pure Prophet. Evaluation remains exploratory: long-history yearly+weekly Prophet succeeds on 50/160 windows, dynamic Prophet succeeds on 140/160 windows, and the full hybrid uses moving-average fallback for 20/160 windows. The 365-day threshold is a project engineering strategy, not a Prophet universal hard requirement. The current holdout/test range has already been inspected for diagnostics, so do not claim fully untouched independent final-test evidence. Shortage comparisons reuse the static 2026-10-10 inventory snapshot as a fixed-inventory scenario, not a true historical inventory backtest. Reports under `reports/generated/` are Git-ignored but reproducible by the documented commands and should be copied into the course delivery package when packaging evidence. Real LangGraph execution is accepted for graph invocation; cross-process recovery is provided by database persistence rather than a durable LangGraph checkpoint backend. The minimal frontend is accepted for the course/demo browser loop, but it remains a demo UI rather than a production ERP frontend.
