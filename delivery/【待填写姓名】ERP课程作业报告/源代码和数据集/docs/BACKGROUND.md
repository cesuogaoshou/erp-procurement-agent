# Background

The course topic is 3.2: AI Agent driven purchase order generation and supplier recommendation algorithm research.

The system demonstrates how an ERP purchasing workflow can combine deterministic business services with LLM-driven orchestration. The autonomous contribution is a reproducible simulated ERP procurement dataset and an evaluation comparing price-only ranking with constraint-filtered four-metric supplier scoring.

The portfolio value is the end-to-end discipline: data generation, forecasting and shortage metrics, supplier recommendation, business safety, approval, traceability, and honest experiment reporting.
